# Stat

A key number with an explanation (Figma "text-field"). Number in `display`, label and description in `body-article`, all white. Always on a dark or image surface.

<Canvas of={S.Grid} />
<Controls of={S.Default} />

## Rules

- Use exactly 4 stats in a `StatGrid`: 2 × 2 from 768px, one column below.
- The grid gap is `gap.L`. Figma draws an off-token 32px.
