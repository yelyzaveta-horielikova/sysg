# Hero text

The page-opening statement (Figma "hero-text"): `display` h1, an optional lead (22/1.3 Light: an off-scale website value hard-coded in the component, not `statement`), and an optional Primary button. Items are 60px apart (`spacing.section.M`), max 1026px wide.

<Canvas of={S.Default} />
<Controls of={S.Default} />

## Rules

- One per page, first block after the header. It holds the page's only h1.
- One button only (Primary).

## Open points

- Figma has no hero background, image or responsive spec.
