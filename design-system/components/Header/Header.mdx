# Header

The global site header, on every page. It switches layout by its own width, which equals the viewport width:

| Width | Content | Height |
|---|---|---|
| ≥1280 (desktop) | logo · 7 nav items · search · Outlined "Contact us" | 100 |
| 480–1279 (tablet) | logo · search · "Contact us" · burger | 104 |
| &lt;480 (mobile) | logo · search · burger | 96 |

<Canvas of={HeaderStories.Desktop} />

## Rules

- It spans the viewport minus the 20px side margins, up to 1920 (not capped at 1520).
- Do not add menu items or actions.
- Nav items with a submenu show a chevron. On hover the label turns sg-medium, a 4px sg-blue underline appears and the chevron flips.

## Not specified in Figma

The submenu or mega-menu content, the search overlay and the burger-menu content. The component exposes `onSearchClick` and `onMenuClick` for these.
